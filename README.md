# FastAPI Production API

This is a backend API built with FastAPI featuring:
- Authentication with JWT
- Student & Item endpoints
- LLM integration with Cohere
- PostgreSQL database (Supabase)
- Clean architecture

## Routes
GET /health
POST /register/
POST /login/
CRUD /students/
CRUD /items/
LLM Chat: /llm/chat
